
# MSDS565 – Movie Genre Classification

## Project Overview
This project explores Natural Language Processing (NLP)
techniques for movie genre classification using textual data.

## Project Objectives
- Perform exploratory data analysis.
- Develop machine learning classification models.
- Evaluate model performance.
- Apply Explainable AI (xAI) techniques to interpret results.

## Repository Structure

MSDS565-MovieGenre-KIA/
│
├── README.md
├── environment.yml
├── models/
└── notebooks/

## Notebooks

1. EDA – Exploratory Data Analysis
2. Modeling – Movie Genre Classification
3. xAI – Explainable Artificial Intelligence

## Technologies
- Python
- NLP
- Scikit-learn
- Jupyter Notebook

## Reproducibility
Install the project environment using:

conda env create -f environment.yml

Activate it using:

conda activate msds565-moviegenre
